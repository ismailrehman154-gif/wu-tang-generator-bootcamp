# Wu-Tang Name Generator

Answer 5 survey questions (yes, maybe, or no) and get your Wu-Tang Clan name. Mine came out "Ruthless Hustle."

![Wu-Tang Name Generator screenshot](screenshot.jpg)

The fun part is the name logic. Five answers go in, and the code has to weigh them and piece together something that sounds like it belongs on a Wu-Tang record. Random enough to be fun, structured enough to make sense.

HTML, CSS, and JavaScript.
